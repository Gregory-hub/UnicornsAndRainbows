Entry workspace for [js13kGames 2026](https://js13kgames.com/2026/), the annual

a **13 kB zip**.

## The rules that actually constrain us

1. **≤ 13,312 bytes** — the `.zip` archive of the game, code *and* assets.
   That's 13 × 1024 (yes, kibibytes).
2. **`index.html` at the top level** of the zip. Unzip → open → playable. No
   build step on the judge's machine.
3. **No external resources.** Everything ships inside the zip. No CDNs, no
   Google Fonts, no Google Analytics, no remote assets. Some categories carve
   out narrow exceptions (see below), but relying on external assets drops you
   out of the overall ranking.
4. **Theme is a rating criterion** — interpret it however you like, but it
   affects the score.
5. **Two sources required on submission:**
   - *Playable* — the zipped package.
   - *Readable* — a public GitHub repo with unmangled source, containing
     everything needed to build the game (not just an unzipped copy of it).
     js13k clones it into their org as a learning resource.
6. **Must work in latest Chrome and Firefox, with zero console errors.**
   Other in-game errors won't disqualify but will hurt ratings.
7. **Namespace your `localStorage` keys.** All games share one origin.
   Never call `localStorage.clear()`.
8. **New content only.** No resubmitting old games/demos, no tutorial-verbatim
   Breakout/Flappy clones. Fresh ideas beat technical polish here.
9. **You must own the rights** to every asset you use.
10. **Teams are fine** (prizes get shared). One draft open at a time; multiple
    submissions allowed, but not the same game split across platforms.
11. Submissions are **manually reviewed** and can be rejected.

Full text: <https://js13kgames.com/2026/rules>

### Tech Q&A worth knowing

- **TypeScript / Rust / WASM: yes**, as long as the shipped package is
  browser-runnable (an actual HTML page, not a binary).
- **WebGL / WebGPU: yes.** See [q1k3](https://js13kgames.com/2021/games/q1k3)
  for what's possible in 13 kB.
- **Web fonts:** only if bundled. You may *optionally* live-load a font for
  exotic glyphs/emoji, but the game must work without it.
- **No plugins/extensions** required from the player.
- Zip must be a plain `.zip` that unpacks anywhere.

## Categories (2026)

Base categories, fully covered by the rules above:

- **Desktop**
- **Mobile**

Categories with their own extra rules:

- **Online** — a WebSocket relay is provided (Cloudflare Durable Objects). You
  may import `partysocket.js` from their server *without* counting it against
  your 13 kB. All game data must be generated by your own code. The game
  **must work offline / single-player**; online features are optional. Rooms
  are ephemeral, nothing is persisted.
  <https://js13kgames.com/2026/online>
- **WebXR** — fine-grained exceptions to the no-external-assets rule.
  Prizes include a Meta Quest 3S. <https://js13kgames.com/2026/webxr>
- **Unfinished** — for drafts that didn't make it, submitted after the main
  deadline.

Plus one challenge:

- **Wavedash** — deploy and publish on Wavedash (deadline extended 7 days, to
  20 September, *for publishing only*). Grand prize $750, runner-up $500,
  third $250; $10 credit for every qualifying participant.
  <https://js13kgames.com/2026/wavedash>

Some category rules are mutually exclusive — ask the organizers if unsure.

## Prizes & judging

Over $30,000 USD in prizes across categories, plus t-shirts and swag shipped
worldwide. Games are rated by community voting and expert judges; theme fit,
originality, gameplay and polish all count.

## Repo layout

```
sandbox/          prototypes — one folder per game idea, not submissions
sandbox/_template a minimal starting point (index.html only)
```

The plan: prototype freely in `sandbox/`, then promote whatever's good into a
proper game folder with a real build.

## Size toolkit

Reach for these once a prototype is worth shrinking:

- [Roadroller](https://lifthrasiir.github.io/roadroller) — JS "flattener",
  usually the single biggest win.
- [Terser](https://terser.org) / [Closure Compiler](https://closure-compiler.appspot.com)
  — minification.
- [RegPack](https://siorki.github.io/regPack.html) — self-extracting packer.
- [ZTML](https://github.com/vshymanskyy/ztml) — inline text compression for HTML/JS.
- **advzip** / [Efficient Compression Tool](https://github.com/fhanau/Efficient-Compression-Tool)
  — recompress the final zip; can take 13 kB down to 9–11 kB.
- [glslx](https://evanw.github.io/glslx/) — GLSL minifier.

Handy libraries (all js13k-sized):

- [Kontra](https://straker.github.io/kontra) — micro game library built for js13k.
- [LittleJS](https://github.com/KilledByAPixel/LittleJS) — 2D engine with WebGL.
- [ZzFX](https://zzfx.3d2k.com) + [ZzFXM](https://keithclark.github.io/ZzFXM)
  — tiny sound effects and music.

Full list: <https://js13kgames.com/2026/resources>
